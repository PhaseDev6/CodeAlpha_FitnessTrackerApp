# VitaFit — AI Fitness Tracker

An **AI-powered Android fitness tracking and wellness companion** built as part of the **CodeAlpha Internship**.

VitaFit combines workout logging, progress analytics, daily reminders, and AI-assisted wellness tools into a single mobile application. It features a modern interface built with Android Material Design and leverages Firebase for backend services and AI logic.

## Key Features

### Fitness Tracking
- **Dashboard:** Personalized dashboard with workout summaries.
- **Workout Log:** Add, search, review, and delete daily workout records.
- **Analytics:** Visualize progress over time with built-in statistics.
- **Reports:** Export workout history as PDF or CSV files.

### AI Fitness Assistant
- **Smart Recommendations:** Profile-aware general fitness suggestions.
- **AI Coach Chat:** Conversational guidance using saved profile data.
- **Diet & Workout Planning:** Generates balanced meal plans and structured workout routines.
- **Progress Analyzer:** Analyzes consistency and activity history to provide actionable feedback.

### App Features
- Secure Firebase Authentication
- Light and Dark Theme support
- Background workout reminders
- Data synchronization via Firebase Realtime Database

## Tech Stack

- **Java & Android SDK**
- **Firebase Authentication & Realtime Database**
- **Firebase AI Logic**
- **Material Components**
